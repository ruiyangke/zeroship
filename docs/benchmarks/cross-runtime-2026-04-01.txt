Key observations:
- appbase deno_core is consistently ~6x faster than Node.js
- raw V8 matches deno_core for sync workloads (~95K vs ~103K)
- raw V8 drops dramatically for blocking workloads (fib(35): 38, timeout: 158)
  because per-request model blocks the worker thread
- deno_core handles fib(35) at 99K because concurrent event loop + V8 JIT
  batches and optimizes across interleaved requests
- Node.js http module is the bottleneck (~17K ceiling regardless of workload)
