## API (dual surface)
```ts
export type HeroAlign = "center" | "start";
interface HeroProps extends Omit<ComponentPropsWithoutRef<"section">, "title"> {
  eyebrow?: ReactNode;       // small label/Badge above the headline
  title: ReactNode;          // the headline (renders as <h1> by default)
  description?: ReactNode;   // supporting paragraph
  actions?: ReactNode;       // CTA buttons (a Cluster of Buttons)
  media?: ReactNode;         // optional image/illustration; when set → split layout
  align?: HeroAlign;         // "center" (default, no media) | "start" (text start-aligned)
}
// Compound: Hero.Eyebrow / .Title / .Description / .Actions / .Media
```
- Root `<section data-slot="hero">` inside a `Container`; vertical `Stack` of
  eyebrow → headline → description → actions. `align="center"` centers the text
  column (max-width measure for readability); `align="start"` start-aligns.
- **media** → a split two-column layout (text column + media column, via Grid/
  Split or flex; collapses to stacked below `--zs-bp-md`). Without media, a
  single centered/start column.
- Headline is an `<h1>` by default (hero is typically the page's primary
  heading); `asChild` on Hero.Title to relevel. Section `aria-labelledby` the
  headline (useId). eyebrow can be a `Badge` (consumer passes) or plain text.
  description = muted `<p>` at a comfortable measure. actions = a `Cluster` of
  the consumer's Buttons (primary + secondary).
- Generous vertical padding (`--zs-space-*` large steps). The section paints no
  heavy background by default (transparent / inherits) — keep it composable into
  a page; consumers add a background. Optional subtle treatment OK if token-pure.
- `forwardRef`, data-slot vocabulary (hero / -eyebrow / -title / -description /
  -actions / -media), per-prop JSDoc. Two-mode props+compound (additive, no
  false suppression).

## a11y
`<section aria-labelledby={titleId}>`; title is a relevelable `<h1>`; media is
decorative (`aria-hidden` wrapper) unless the consumer passes a labelled image;
actions are real Buttons. forced-colors: text stays legible (CanvasText).

## Constraints
`--zs-*` only; no raw hex/px (rem/%/dvh ok); logical properties; forced-colors +
reduced-motion; no "HIG"/"Apple"; pre-launch no-back-compat. Story
`layout: "fullscreen"`.
