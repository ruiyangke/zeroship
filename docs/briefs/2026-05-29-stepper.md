# Slice brief: Stepper block

A governed multi-step progress indicator / wizard nav: ordered steps with
complete / current / upcoming state, labels (+ optional descriptions),
connectors, horizontal or vertical, optionally clickable. Composes Icon
(Lucide Check for complete) + Stack/Cluster. Lives in
`sdks/ui/src/blocks/Stepper/`.

## Reference / compose
`components/Icon` (+ lucide `Check` for complete steps, decorative),
`layouts/{Stack,Cluster}`, `components/_classnames`. House: forwardRef, data-slot,
per-prop JSDoc. Token intent: accent for current/complete, muted for upcoming.

## API
```ts
export type StepperOrientation = "horizontal" | "vertical";
export type StepStatus = "complete" | "current" | "upcoming";
interface StepperStep { id: string; label: ReactNode; description?: ReactNode; status?: StepStatus; }
interface StepperProps extends ComponentPropsWithoutRef<"ol"> {
  steps: StepperStep[];
  current?: number | string;     // active step index OR id (default 0)
  orientation?: StepperOrientation; // default "horizontal"
  onStepChange?: (id: string, index: number) => void; // when set → steps are clickable
}
```
- Derive each step's status (unless `step.status` explicitly set): index <
  current → `complete`; === current → `current`; > current → `upcoming`.
  (`current` accepts an index or an id.)
- Each step renders an **indicator** + a text column (label + optional
  description), separated by **connectors** (a line between indicators).
  - complete → accent-filled indicator with a `Check` `Icon` (aria-hidden).
  - current → accent-ringed/filled indicator showing the step number; the row
    is marked `aria-current="step"`.
  - upcoming → muted indicator showing the number.
- **Clickable**: when `onStepChange` set, each step's indicator+label is a real
  `<button type="button">` calling `onStepChange(id,index)`; else static text.
  (Typically only complete/current steps are navigable — keep all clickable but
  document; consumers can gate via the callback.)
- `horizontal` = a `Cluster`/row of step+connector; `vertical` = a `Stack`/column
  (connector is a vertical line). Connector reflects completion (accent up to the
  current step, muted after).
- `forwardRef`, data-slot vocabulary (stepper / -step / -indicator / -label /
  -description / -connector), per-prop JSDoc.

## a11y
Root `<ol data-slot="stepper">` (ordered). Each step `<li>`; the CURRENT step
carries `aria-current="step"`. Each step's status is conveyed by MORE than color:
the complete check glyph + a visually-hidden status word ("completed" / "current
step" / "upcoming") so SR users get state without relying on the accent color.
Clickable steps are real `<button>`s (keyboard/focus native + focus-visible
ring). Connectors + the check Icon are `aria-hidden`.

## Constraints
`--zs-*` only; no raw hex/px; logical properties; forced-colors (indicators/
connectors/current stay distinguishable) + reduced-motion; no "HIG"/"Apple";
pre-launch no-back-compat. Export from `blocks/index.ts`; `@import` CSS into
styles.css (Composed blocks); story `layout: "fullscreen"`.
