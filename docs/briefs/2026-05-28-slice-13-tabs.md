  extends Omit<BaseTabsRootProps<Value>, "render"> {
  /** Visual variant — `default` underline indicator / `pill` accent-fill segmented / `card` raised tab cards. */

  /** Lazy-mount panel content (default false — all panels render). */

## Contingencies (decide inline)

- **Indicator animation**: track left/right + width via `transform: translateX` + width animation. prefers-reduced-motion → no transition.
- **Vertical orientation**: List becomes column; indicator translates vertically.
- **Variant: pill**: like Toggle.Group's pressed pill — accent-fill rounded rect.
- **Variant: card**: each tab is an opaque surface raised slightly from the list; active tab merges into the panel surface.
- **Forced-colors mirror**: standard.
