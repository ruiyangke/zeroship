# appbase-pg Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal compio-native PostgreSQL driver (`crates/pg/`) that replaces sqlx in the platform crate, eliminating the tokio dependency from the database layer.

**Architecture:** Uses `postgres-protocol` for wire format encoding/decoding and SCRAM-SHA-256 auth (battle-tested, zero runtime dependency). We write only the compio I/O layer (`stream.rs`), connection lifecycle (`conn.rs`), connection pool (`pool.rs`), and public API (`lib.rs`). ~850 lines total across 4 source files.

**Tech Stack:** postgres-protocol 0.6, postgres-types 0.2, bytes 1, compio 0.18 (io_uring), compio-tls 0.9 (optional)

```rust
#[derive(Debug)]
pub enum Error {
    /// PostgreSQL error response (severity, SQLSTATE code, message).
    Postgres {
        severity: String,
        code: String,
        message: String,
    },
    /// I/O error (connection refused, timeout, broken pipe).
    Io(std::io::Error),
    /// Wire protocol violation (unexpected message, malformed data).
    Protocol(String),
    /// Authentication failure (bad password, unsupported mechanism).
    Auth(String),
    /// Connection pool exhausted.
    Pool(String),
    /// TLS negotiation failure.
    Tls(String),
}

impl std::fmt::Display for Error {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::Postgres { severity, code, message } => {
                write!(f, "pg error ({severity}/{code}): {message}")
            }
            Self::Io(e) => write!(f, "I/O error: {e}"),
            Self::Protocol(msg) => write!(f, "protocol error: {msg}"),
            Self::Auth(msg) => write!(f, "auth error: {msg}"),
            Self::Pool(msg) => write!(f, "pool error: {msg}"),
            Self::Tls(msg) => write!(f, "TLS error: {msg}"),
        }
    }
}

impl std::error::Error for Error {}

impl From<std::io::Error> for Error {
    fn from(e: std::io::Error) -> Self {
        Self::Io(e)
    }
}

pub type Result<T> = std::result::Result<T, Error>;

// ---------------------------------------------------------------------------
// Row + Column
// ---------------------------------------------------------------------------

/// A single row returned from a query.
pub struct Row {
    columns: Arc<Vec<Column>>,
    values: Vec<Option<Vec<u8>>>,
}

/// Column metadata from RowDescription.
#[derive(Debug, Clone)]
pub struct Column {
    pub name: String,
    pub oid: u32,
}

impl Row {
    /// Get a column value by name, panicking if missing or wrong type.
    pub fn get<'a, T>(&'a self, column: &str) -> T
    where
        T: FromSql<'a>,
    {
        self.try_get(column)
            .unwrap_or_else(|e| panic!("column '{column}': {e}"))
    }

    /// Get a column value by name, returning an error if missing or wrong type.
    pub fn try_get<'a, T>(&'a self, column: &str) -> Result<T>
    where
        T: FromSql<'a>,
    {
        let idx = self
            .columns
            .iter()
            .position(|c| c.name == column)
            .ok_or_else(|| Error::Protocol(format!("no column '{column}'")))?;

        let col = &self.columns[idx];
        let pg_type = Type::from_oid(col.oid).unwrap_or(Type::TEXT);

        match &self.values[idx] {
            Some(bytes) => T::from_sql(&pg_type, bytes)
                .map_err(|e| Error::Protocol(format!("column '{column}': {e}"))),
            None => T::from_sql_null(&pg_type)
                .map_err(|e| Error::Protocol(format!("column '{column}' is null: {e}"))),
        }
    }

    /// Returns the number of columns.
    pub fn len(&self) -> usize {
        self.columns.len()
    }

    /// Returns true if the row has no columns.
    pub fn is_empty(&self) -> bool {
        self.columns.is_empty()
    }

    /// Returns the column metadata.
    pub fn columns(&self) -> &[Column] {
        &self.columns
    }
}

impl std::fmt::Debug for Row {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("Row")
            .field("columns", &self.columns)
            .field("values", &format_args!("[{} values]", self.values.len()))
            .finish()
    }
}
```

- [ ] **Step 1: Implement BufStream**

```rust
//! Buffered compio I/O for PostgreSQL connections.
//!
//! Wraps compio's TcpStream with an 8KB userspace read buffer to amortize
//! io_uring submissions. Without buffering, parsing one Postgres message
//! (1-byte tag + 4-byte length + payload) would be 3 separate io_uring SQEs.

use bytes::BytesMut;
use compio::buf::BufResult;
use compio::io::AsyncWrite;
use compio::net::TcpStream;

use crate::{Error, Result};

const READ_BUF_CAPACITY: usize = 8192;

pub(crate) enum StreamInner {
    Tcp(TcpStream),
    #[cfg(feature = "tls")]
    Tls(compio_tls::TlsStream<TcpStream>),
}

/// Buffered read/write stream over a compio TcpStream (or TlsStream).
pub(crate) struct BufStream {
    inner: StreamInner,
    read_buf: BytesMut,
    write_buf: BytesMut,
}

impl BufStream {
    /// Wrap a TCP stream.
    pub fn tcp(stream: TcpStream) -> Self {
        Self {
            inner: StreamInner::Tcp(stream),
            read_buf: BytesMut::with_capacity(READ_BUF_CAPACITY),
            write_buf: BytesMut::with_capacity(1024),
        }
    }

    /// Wrap a TLS stream.
    #[cfg(feature = "tls")]
    pub fn tls(stream: compio_tls::TlsStream<TcpStream>) -> Self {
        Self {
            inner: StreamInner::Tls(stream),
            read_buf: BytesMut::with_capacity(READ_BUF_CAPACITY),
            write_buf: BytesMut::with_capacity(1024),
        }
    }

    /// Ensure the read buffer has at least `min_bytes` available.
    /// Reads from the socket if needed. Returns error on EOF or I/O failure.
    pub async fn fill(&mut self, min_bytes: usize) -> Result<()> {
        while self.read_buf.len() < min_bytes {
            let capacity = READ_BUF_CAPACITY.max(min_bytes - self.read_buf.len());
            let buf = vec![0u8; capacity];
            let (n, buf) = self.read_raw(buf).await?;
            if n == 0 {
                return Err(Error::Io(std::io::Error::new(
                    std::io::ErrorKind::UnexpectedEof,
                    "connection closed by server",
                )));
            }
            self.read_buf.extend_from_slice(&buf[..n]);
        }
        Ok(())
    }

    /// Access the read buffer for `Message::parse()` to consume from.
    pub fn buf(&mut self) -> &mut BytesMut {
        &mut self.read_buf
    }

    /// Read exactly one byte from the stream (used for SSL negotiation response).
    pub async fn read_byte(&mut self) -> Result<u8> {
        self.fill(1).await?;
        Ok(self.read_buf.split_to(1)[0])
    }

    /// Append data to the write buffer (no I/O until flush).
    pub fn write(&mut self, data: &[u8]) {
        self.write_buf.extend_from_slice(data);
    }

    /// Append a BytesMut to the write buffer (no I/O until flush).
    pub fn write_bytes(&mut self, data: &BytesMut) {
        self.write_buf.extend_from_slice(data);
    }

    /// Flush the write buffer to the socket.
    pub async fn flush(&mut self) -> Result<()> {
        if self.write_buf.is_empty() {
            return Ok(());
        }
        let data = self.write_buf.split().freeze().to_vec();
        self.write_all_raw(data).await?;
        Ok(())
    }

    /// Low-level read into owned buffer, returning (bytes_read, buffer).
    async fn read_raw(&mut self, buf: Vec<u8>) -> Result<(usize, Vec<u8>)> {
        use compio::io::AsyncRead;
        let BufResult(result, returned) = match &mut self.inner {
            StreamInner::Tcp(s) => s.read(buf).await,
            #[cfg(feature = "tls")]
            StreamInner::Tls(s) => s.read(buf).await,
        };
        let n = result?;
        Ok((n, returned))
    }

    /// Low-level write all bytes to the socket.
    async fn write_all_raw(&mut self, data: Vec<u8>) -> Result<()> {
        let BufResult(result, _) = match &mut self.inner {
            StreamInner::Tcp(s) => s.write_all(data).await,
            #[cfg(feature = "tls")]
            StreamInner::Tls(s) => s.write_all(data).await,
        };
        result?;
        Ok(())
    }

    /// Get a reference to the underlying TCP stream (for TLS upgrade).
    #[cfg(feature = "tls")]
    pub fn into_tcp(self) -> std::result::Result<TcpStream, Self> {
        match self.inner {
            StreamInner::Tcp(s) => Ok(s),
            #[cfg(feature = "tls")]
            _ => Err(self),
        }
    }
}
```

```rust
//! PostgreSQL connection — startup, auth, query, execute.
//!
//! Uses postgres-protocol for wire format encoding/decoding and SCRAM-SHA-256.
//! All I/O goes through BufStream (buffered compio).

use std::collections::HashMap;
use std::sync::Arc;

use bytes::BytesMut;
use compio::net::TcpStream;
use postgres_protocol::authentication::sasl;
use postgres_protocol::authentication::sasl::ScramSha256;
use postgres_protocol::message::{backend, frontend};

use crate::stream::BufStream;
use crate::{Column, Error, Result, Row};

/// Parsed connection URL.
struct ConnectConfig {
    pub host: String,
    pub port: u16,
    pub user: String,
    pub password: String,
    pub database: String,
    pub sslmode: SslMode,
}

#[derive(Debug, Clone, Copy, PartialEq)]
enum SslMode {
    Disable,
    Prefer,
    Require,
}

fn parse_url(url: &str) -> Result<ConnectConfig> {
    // postgres://user:password@host:port/database?sslmode=prefer
    let url = if url.starts_with("postgresql://") {
        url.replacen("postgresql://", "postgres://", 1)
    } else {
        url.to_string()
    };

    let parsed = url::Url::parse(&url)
        .map_err(|e| Error::Protocol(format!("invalid connection URL: {e}")))?;

    let host = parsed.host_str().unwrap_or("localhost").to_string();
    let port = parsed.port().unwrap_or(5432);
    let user = if parsed.username().is_empty() {
        "postgres".to_string()
    } else {
        parsed.username().to_string()
    };
    let password = parsed.password().unwrap_or("").to_string();
    let database = parsed.path().trim_start_matches('/').to_string();
    let database = if database.is_empty() {
        user.clone()
    } else {
        database
    };

    let sslmode = parsed
        .query_pairs()
        .find(|(k, _)| k == "sslmode")
        .map(|(_, v)| match v.as_ref() {
            "disable" => SslMode::Disable,
            "require" => SslMode::Require,
            _ => SslMode::Prefer,
        })
        .unwrap_or(SslMode::Prefer);

    Ok(ConnectConfig {
        host,
        port,
        user,
        password,
        database,
        sslmode,
    })
}

/// A PostgreSQL connection.
pub struct Conn {
    stream: BufStream,
    #[allow(dead_code)]
    pid: i32,
    #[allow(dead_code)]
    secret: i32,
    #[allow(dead_code)]
    params: HashMap<String, String>,
    status: u8,
    pub(crate) needs_rollback: bool,
}

impl Conn {
    /// Connect to a PostgreSQL server.
    ///
    /// URL format: `postgres://user:password@host:port/database?sslmode=prefer`
    pub async fn connect(url: &str) -> Result<Self> {
        let config = parse_url(url)?;
        let addr = format!("{}:{}", config.host, config.port);
        let tcp = TcpStream::connect(&addr).await?;

        let mut stream = BufStream::tcp(tcp);

        // TLS negotiation
        #[cfg(feature = "tls")]
        if config.sslmode != SslMode::Disable {
            let mut ssl_buf = BytesMut::new();
            frontend::ssl_request(&mut ssl_buf);
            stream.write(&ssl_buf);
            stream.flush().await?;

            let response = stream.read_byte().await?;
            if response == b'S' {
                // Server accepts TLS — upgrade
                let tcp = stream.into_tcp().map_err(|_| {
                    Error::Tls("failed to extract TCP stream for TLS upgrade".into())
                })?;
                let connector = compio_tls::native_tls::TlsConnector::builder()
                    .danger_accept_invalid_certs(true) // TODO: proper cert validation
                    .build()
                    .map_err(|e| Error::Tls(e.to_string()))?;
                let connector = compio_tls::TlsConnector::from(connector);
                let tls_stream = connector
                    .connect(&config.host, tcp)
                    .await
                    .map_err(|e| Error::Tls(e.to_string()))?;
                stream = BufStream::tls(tls_stream);
            } else if config.sslmode == SslMode::Require {
                return Err(Error::Tls("server rejected TLS but sslmode=require".into()));
            }
            // else: sslmode=prefer, server said 'N', continue without TLS
        }

        #[cfg(not(feature = "tls"))]
        if config.sslmode == SslMode::Require {
            return Err(Error::Tls(
                "TLS required but appbase-pg compiled without 'tls' feature".into(),
            ));
        }

        // Startup message
        let mut buf = BytesMut::new();
        frontend::startup_message(
            [("user", config.user.as_str()), ("database", config.database.as_str())]
                .iter()
                .copied(),
            &mut buf,
        )
        .map_err(|e| Error::Protocol(format!("startup: {e}")))?;
        stream.write(&buf);
        stream.flush().await?;

        // Auth + startup response loop
        let mut pid = 0i32;
        let mut secret = 0i32;
        let mut params = HashMap::new();
        let mut status = b'I';

        loop {
            stream.fill(5).await?; // at least tag + length
            let msg = match backend::Message::parse(stream.buf())
                .map_err(|e| Error::Protocol(format!("parse: {e}")))?
            {
                Some(msg) => msg,
                None => {
                    stream.fill(stream.buf().len() + 1).await?;
                    continue;
                }
            };

            match msg {
                backend::Message::AuthenticationSasl(body) => {
                    let mut mechanisms = body.mechanisms();
                    let mut found_scram = false;
                    while let Some(mech) = mechanisms
                        .next()
                        .map_err(|e| Error::Auth(format!("SASL mechanisms: {e}")))?
                    {
                        if mech == sasl::SCRAM_SHA_256 {
                            found_scram = true;
                            break;
                        }
                    }
                    if !found_scram {
                        return Err(Error::Auth(
                            "server does not support SCRAM-SHA-256".into(),
                        ));
                    }

                    let mut scram = ScramSha256::new(
                        config.password.as_bytes(),
                        sasl::ChannelBinding::unsupported(),
                    );

                    // Send SASLInitialResponse
                    let mut buf = BytesMut::new();
                    frontend::sasl_initial_response(sasl::SCRAM_SHA_256, scram.message(), &mut buf)
                        .map_err(|e| Error::Auth(format!("SASL initial: {e}")))?;
                    stream.write(&buf);
                    stream.flush().await?;

                    // Read SASLContinue
                    loop {
                        stream.fill(5).await?;
                        if let Some(msg) = backend::Message::parse(stream.buf())
                            .map_err(|e| Error::Protocol(format!("parse: {e}")))?
                        {
                            match msg {
                                backend::Message::AuthenticationSaslContinue(body) => {
                                    scram
                                        .update(body.data())
                                        .map_err(|e| Error::Auth(format!("SCRAM update: {e}")))?;
                                    break;
                                }
                                backend::Message::ErrorResponse(body) => {
                                    return Err(parse_error_response(body));
                                }
                                _ => {
                                    return Err(Error::Protocol(
                                        "expected AuthenticationSaslContinue".into(),
                                    ));
                                }
                            }
                        }
                    }

                    // Send SASLResponse
                    let mut buf = BytesMut::new();
                    frontend::sasl_response(scram.message(), &mut buf)
                        .map_err(|e| Error::Auth(format!("SASL response: {e}")))?;
                    stream.write(&buf);
                    stream.flush().await?;

                    // Read SASLFinal
                    loop {
                        stream.fill(5).await?;
                        if let Some(msg) = backend::Message::parse(stream.buf())
                            .map_err(|e| Error::Protocol(format!("parse: {e}")))?
                        {
                            match msg {
                                backend::Message::AuthenticationSaslFinal(body) => {
                                    scram
                                        .finish(body.data())
                                        .map_err(|e| Error::Auth(format!("SCRAM finish: {e}")))?;
                                    break;
                                }
                                backend::Message::ErrorResponse(body) => {
                                    return Err(parse_error_response(body));
                                }
                                _ => {
                                    return Err(Error::Protocol(
                                        "expected AuthenticationSaslFinal".into(),
                                    ));
                                }
                            }
                        }
                    }
                }
                backend::Message::AuthenticationCleartextPassword => {
                    let mut buf = BytesMut::new();
                    frontend::password_message(config.password.as_bytes(), &mut buf)
                        .map_err(|e| Error::Auth(format!("password: {e}")))?;
                    stream.write(&buf);
                    stream.flush().await?;
                }
                backend::Message::AuthenticationOk => {
                    // Auth complete, continue to consume startup params
                }
                backend::Message::ParameterStatus(body) => {
                    params.insert(
                        body.name().map_err(|e| Error::Protocol(e.to_string()))?.to_string(),
                        body.value().map_err(|e| Error::Protocol(e.to_string()))?.to_string(),
                    );
                }
                backend::Message::BackendKeyData(body) => {
                    pid = body.process_id();
                    secret = body.secret_key();
                }
                backend::Message::ReadyForQuery(body) => {
                    status = body.status();
                    break;
                }
                backend::Message::ErrorResponse(body) => {
                    return Err(parse_error_response(body));
                }
                backend::Message::NoticeResponse(_) => {
                    // Ignore notices during startup
                }
                _ => {
                    // Ignore unknown messages during startup
                }
            }
        }

        Ok(Self {
            stream,
            pid,
            secret,
            params,
            status,
            needs_rollback: false,
        })
    }

    /// Returns the connection's transaction status: 'I' idle, 'T' in txn, 'E' error.
    pub fn status(&self) -> u8 {
        self.status
    }

    /// Send Terminate and close the connection.
    pub async fn close(mut self) -> Result<()> {
        let mut buf = BytesMut::new();
        frontend::terminate(&mut buf);
        self.stream.write(&buf);
        self.stream.flush().await?;
        Ok(())
    }
}

/// Read the next backend message, filling the buffer as needed.
async fn read_message(stream: &mut BufStream) -> Result<backend::Message> {
    loop {
        stream.fill(5).await?;
        if let Some(msg) = backend::Message::parse(stream.buf())
            .map_err(|e| Error::Protocol(format!("parse: {e}")))?
        {
            return Ok(msg);
        }
    }
}

/// Parse an ErrorResponse into our Error type.
fn parse_error_response(body: backend::ErrorResponseBody) -> Error {
    let mut severity = String::new();
    let mut code = String::new();
    let mut message = String::new();
    let mut fields = body.fields();
    while let Ok(Some(field)) = fields.next() {
        match field.type_() {
            b'S' | b'V' => severity = field.value().to_string(),
            b'C' => code = field.value().to_string(),
            b'M' => message = field.value().to_string(),
            _ => {}
        }
    }
    Error::Postgres {
        severity,
        code,
        message,
    }
}
```

```rust
    /// Execute a query and return rows.
    ///
    /// Uses the Extended Query Protocol: Parse → Bind → Describe → Execute → Sync,
    /// all pipelined in one TCP flush.
    pub async fn query(&mut self, sql: &str, params: &[&(dyn ToSql + Sync)]) -> Result<Vec<Row>> {
        self.send_extended_query(sql, params, true).await?;
        self.read_query_response().await
    }

    /// Execute a statement and return the number of affected rows.
    pub async fn execute(&mut self, sql: &str, params: &[&(dyn ToSql + Sync)]) -> Result<u64> {
        self.send_extended_query(sql, params, false).await?;
        self.read_execute_response().await
    }

    /// Begin a transaction.
    pub async fn begin(&mut self) -> Result<Transaction<'_>> {
        self.execute("BEGIN", &[]).await?;
        Ok(Transaction {
            conn: self,
            done: false,
        })
    }

    /// Send Parse + Bind + optionally Describe + Execute + Sync, then flush.
    async fn send_extended_query(
        &mut self,
        sql: &str,
        params: &[&(dyn ToSql + Sync)],
        describe: bool,
    ) -> Result<()> {
        let mut buf = BytesMut::new();

        // Encode parameter values as binary
        let mut param_values: Vec<Option<Vec<u8>>> = Vec::with_capacity(params.len());
        let mut param_oids: Vec<u32> = Vec::with_capacity(params.len());
        for p in params {
            let ty = p.type_();
            param_oids.push(ty.oid());
            let mut val_buf = BytesMut::new();
            // Check if the value is NULL
            if postgres_types::ToSql::accepts(*p, &ty) {
                let is_null = postgres_types::ToSql::to_sql(
                    *p,
                    &ty,
                    &mut val_buf,
                )
                .map_err(|e| Error::Protocol(format!("param encode: {e}")))?;
                match is_null {
                    postgres_types::IsNull::Yes => param_values.push(None),
                    postgres_types::IsNull::No => param_values.push(Some(val_buf.to_vec())),
                }
            } else {
                param_values.push(None);
            }
        }

        // Parse (unnamed statement)
        frontend::parse("", sql, param_oids.iter().copied(), &mut buf)
            .map_err(|e| Error::Protocol(format!("parse: {e}")))?;

        // Bind (unnamed portal, binary format for params, text format for results)
        frontend::bind(
            "",                          // unnamed portal
            "",                          // unnamed statement
            std::iter::empty(),          // param formats (empty = all text)
            param_values.iter().map(|v| v.as_deref()),  // param values
            |v, buf| {
                buf.extend_from_slice(v);
                Ok(postgres_protocol::IsNull::No)
            },
            std::iter::empty(),          // result formats (empty = all text)
            &mut buf,
        )
        .map_err(|e| Error::Protocol(format!("bind: {e}")))?;

        // Describe portal (to get RowDescription)
        if describe {
            frontend::describe(b'P', "", &mut buf)
                .map_err(|e| Error::Protocol(format!("describe: {e}")))?;
        }

        // Execute (unnamed portal, fetch all rows)
        frontend::execute("", 0, &mut buf)
            .map_err(|e| Error::Protocol(format!("execute: {e}")))?;

        // Sync
        frontend::sync(&mut buf);

        self.stream.write(&buf);
        self.stream.flush().await?;
        Ok(())
    }

    /// Read response for a query (with RowDescription and DataRows).
    async fn read_query_response(&mut self) -> Result<Vec<Row>> {
        // Read ParseComplete
        expect_message(&mut self.stream, |m| {
            matches!(m, backend::Message::ParseComplete)
        }, "ParseComplete").await?;

        // Read BindComplete
        expect_message(&mut self.stream, |m| {
            matches!(m, backend::Message::BindComplete)
        }, "BindComplete").await?;

        // Read RowDescription (or NoData for non-SELECT)
        let columns: Arc<Vec<Column>> = match read_message(&mut self.stream).await? {
            backend::Message::RowDescription(body) => {
                let mut cols = Vec::new();
                let mut fields = body.fields();
                while let Some(field) = fields
                    .next()
                    .map_err(|e| Error::Protocol(format!("row desc: {e}")))?
                {
                    cols.push(Column {
                        name: field.name().to_string(),
                        oid: field.type_oid(),
                    });
                }
                Arc::new(cols)
            }
            backend::Message::NoData => Arc::new(Vec::new()),
            other => {
                return Err(Error::Protocol(format!(
                    "expected RowDescription or NoData, got {:?}",
                    msg_tag(&other)
                )));
            }
        };

        // Read DataRows until CommandComplete
        let mut rows = Vec::new();
        loop {
            match read_message(&mut self.stream).await? {
                backend::Message::DataRow(body) => {
                    let mut values = Vec::with_capacity(columns.len());
                    let mut ranges = body.ranges();
                    for _ in 0..columns.len() {
                        let range = ranges
                            .next()
                            .map_err(|e| Error::Protocol(format!("data row: {e}")))?;
                        match range {
                            Some(range) => {
                                values.push(Some(body.buffer()[range].to_vec()));
                            }
                            None => values.push(None),
                        }
                    }
                    rows.push(Row {
                        columns: columns.clone(),
                        values,
                    });
                }
                backend::Message::CommandComplete(_) => break,
                backend::Message::ErrorResponse(body) => {
                    // Drain until ReadyForQuery
                    drain_until_ready(&mut self.stream, &mut self.status).await?;
                    return Err(parse_error_response(body));
                }
                other => {
                    return Err(Error::Protocol(format!(
                        "expected DataRow or CommandComplete, got {:?}",
                        msg_tag(&other)
                    )));
                }
            }
        }

        // Read ReadyForQuery
        match read_message(&mut self.stream).await? {
            backend::Message::ReadyForQuery(body) => {
                self.status = body.status();
            }
            other => {
                return Err(Error::Protocol(format!(
                    "expected ReadyForQuery, got {:?}",
                    msg_tag(&other)
                )));
            }
        }

        Ok(rows)
    }

    /// Read response for execute (no RowDescription, just CommandComplete).
    async fn read_execute_response(&mut self) -> Result<u64> {
        // Read ParseComplete
        expect_message(&mut self.stream, |m| {
            matches!(m, backend::Message::ParseComplete)
        }, "ParseComplete").await?;

        // Read BindComplete
        expect_message(&mut self.stream, |m| {
            matches!(m, backend::Message::BindComplete)
        }, "BindComplete").await?;

        // Read DataRows (discard) + CommandComplete
        let mut affected = 0u64;
        loop {
            match read_message(&mut self.stream).await? {
                backend::Message::DataRow(_) => {
                    // Discard rows for execute()
                }
                backend::Message::CommandComplete(body) => {
                    let tag = body
                        .tag()
                        .map_err(|e| Error::Protocol(format!("command tag: {e}")))?;
                    // Parse "INSERT 0 5" or "DELETE 3" or "UPDATE 2" or "SELECT 5"
                    affected = tag
                        .rsplit(' ')
                        .next()
                        .and_then(|s| s.parse().ok())
                        .unwrap_or(0);
                    break;
                }
                backend::Message::ErrorResponse(body) => {
                    drain_until_ready(&mut self.stream, &mut self.status).await?;
                    return Err(parse_error_response(body));
                }
                _ => {}
            }
        }

        // Read ReadyForQuery
        match read_message(&mut self.stream).await? {
            backend::Message::ReadyForQuery(body) => {
                self.status = body.status();
            }
            _ => {}
        }

        Ok(affected)
    }
}

/// A database transaction. Sends ROLLBACK on drop if not committed.
pub struct Transaction<'a> {
    conn: &'a mut Conn,
    done: bool,
}

impl Transaction<'_> {
    /// Execute a query within the transaction.
    pub async fn query(&mut self, sql: &str, params: &[&(dyn ToSql + Sync)]) -> Result<Vec<Row>> {
        self.conn.query(sql, params).await
    }

    /// Execute a statement within the transaction.
    pub async fn execute(&mut self, sql: &str, params: &[&(dyn ToSql + Sync)]) -> Result<u64> {
        self.conn.execute(sql, params).await
    }

    /// Commit the transaction.
    pub async fn commit(mut self) -> Result<()> {
        self.conn.execute("COMMIT", &[]).await?;
        self.done = true;
        Ok(())
    }

    /// Rollback the transaction.
    pub async fn rollback(mut self) -> Result<()> {
        self.conn.execute("ROLLBACK", &[]).await?;
        self.done = true;
        Ok(())
    }
}

impl Drop for Transaction<'_> {
    fn drop(&mut self) {
        if !self.done {
            self.conn.needs_rollback = true;
        }
    }
}

/// Read messages until we find one matching the predicate.
async fn expect_message(
    stream: &mut BufStream,
    pred: impl Fn(&backend::Message) -> bool,
    expected: &str,
) -> Result<()> {
    loop {
        let msg = read_message(stream).await?;
        if pred(&msg) {
            return Ok(());
        }
        if let backend::Message::ErrorResponse(body) = msg {
            return Err(parse_error_response(body));
        }
        if let backend::Message::NoticeResponse(_) = msg {
            continue; // skip notices
        }
        return Err(Error::Protocol(format!(
            "expected {expected}, got {:?}",
            msg_tag(&msg)
        )));
    }
}

/// Drain messages until ReadyForQuery (after an error).
async fn drain_until_ready(stream: &mut BufStream, status: &mut u8) -> Result<()> {
    loop {
        match read_message(stream).await? {
            backend::Message::ReadyForQuery(body) => {
                *status = body.status();
                return Ok(());
            }
            _ => continue,
        }
    }
}

/// Debug tag for a message (for error reporting).
fn msg_tag(msg: &backend::Message) -> &'static str {
    match msg {
        backend::Message::AuthenticationOk => "AuthenticationOk",
        backend::Message::AuthenticationSasl(_) => "AuthenticationSasl",
        backend::Message::AuthenticationSaslContinue(_) => "AuthenticationSaslContinue",
        backend::Message::AuthenticationSaslFinal(_) => "AuthenticationSaslFinal",
        backend::Message::AuthenticationCleartextPassword => "AuthenticationCleartextPassword",
        backend::Message::BackendKeyData(_) => "BackendKeyData",
        backend::Message::BindComplete => "BindComplete",
        backend::Message::CommandComplete(_) => "CommandComplete",
        backend::Message::DataRow(_) => "DataRow",
        backend::Message::ErrorResponse(_) => "ErrorResponse",
        backend::Message::NoData => "NoData",
        backend::Message::NoticeResponse(_) => "NoticeResponse",
        backend::Message::ParameterDescription(_) => "ParameterDescription",
        backend::Message::ParameterStatus(_) => "ParameterStatus",
        backend::Message::ParseComplete => "ParseComplete",
        backend::Message::ReadyForQuery(_) => "ReadyForQuery",
        backend::Message::RowDescription(_) => "RowDescription",
        _ => "Unknown",
    }
}
```

```rust
//! Single-threaded connection pool (Rc-based, fits compio's model).
//!
//! Each compio worker gets its own pool. Connections are borrowed via
//! `PooledConn` and returned on drop if still healthy.

use std::cell::{Cell, RefCell};
use std::ops::{Deref, DerefMut};

use crate::conn::Conn;
use crate::{Error, Result, Row, ToSql};

/// A single-threaded connection pool.
pub struct Pool {
    url: String,
    conns: RefCell<Vec<Conn>>,
    max_size: usize,
    total: Cell<usize>,
}

impl Pool {
    /// Create a new pool. Eagerly opens one connection to verify the URL.
    pub async fn connect(url: &str, max_size: usize) -> Result<Self> {
        let conn = Conn::connect(url).await?;
        let pool = Self {
            url: url.to_string(),
            conns: RefCell::new(vec![conn]),
            max_size,
            total: Cell::new(1),
        };
        Ok(pool)
    }

    /// Acquire a connection from the pool.
    pub async fn get(&self) -> Result<PooledConn<'_>> {
        // Try to pop an idle connection
        let conn = self.conns.borrow_mut().pop();
        if let Some(mut conn) = conn {
            // If the connection needs a rollback from a dropped transaction, send it
            if conn.needs_rollback {
                let _ = conn.execute("ROLLBACK", &[]).await;
                conn.needs_rollback = false;
            }
            return Ok(PooledConn {
                conn: Some(conn),
                pool: self,
            });
        }

        // No idle connections — create a new one if under limit
        if self.total.get() < self.max_size {
            let conn = Conn::connect(&self.url).await?;
            self.total.set(self.total.get() + 1);
            return Ok(PooledConn {
                conn: Some(conn),
                pool: self,
            });
        }

        Err(Error::Pool(format!(
            "pool exhausted (max_size={})",
            self.max_size
        )))
    }

    /// Convenience: acquire a connection, run a query, return the connection.
    pub async fn query(&self, sql: &str, params: &[&(dyn ToSql + Sync)]) -> Result<Vec<Row>> {
        let mut conn = self.get().await?;
        conn.query(sql, params).await
    }

    /// Convenience: acquire a connection, execute a statement, return the connection.
    pub async fn execute(&self, sql: &str, params: &[&(dyn ToSql + Sync)]) -> Result<u64> {
        let mut conn = self.get().await?;
        conn.execute(sql, params).await
    }

    /// Return a connection to the pool (called by PooledConn::drop).
    fn return_conn(&self, conn: Conn) {
        // Only return healthy connections
        if conn.status() == b'I' || conn.status() == b'T' {
            self.conns.borrow_mut().push(conn);
        } else {
            // Unhealthy — drop it, decrement total
            self.total.set(self.total.get().saturating_sub(1));
        }
    }
}

impl std::fmt::Debug for Pool {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("Pool")
            .field("url", &"***")
            .field("idle", &self.conns.borrow().len())
            .field("total", &self.total.get())
            .field("max_size", &self.max_size)
            .finish()
    }
}

/// A borrowed connection that returns to the pool on drop.
pub struct PooledConn<'a> {
    conn: Option<Conn>,
    pool: &'a Pool,
}

impl Deref for PooledConn<'_> {
    type Target = Conn;
    fn deref(&self) -> &Self::Target {
        self.conn.as_ref().unwrap()
    }
}

impl DerefMut for PooledConn<'_> {
    fn deref_mut(&mut self) -> &mut Self::Target {
        self.conn.as_mut().unwrap()
    }
}

impl Drop for PooledConn<'_> {
    fn drop(&mut self) {
        if let Some(conn) = self.conn.take() {
            self.pool.return_conn(conn);
        }
    }
}
```

```rust
}
```
