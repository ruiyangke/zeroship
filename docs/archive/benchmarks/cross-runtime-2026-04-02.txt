Cross-Runtime RPC Benchmark
Date: 2026-04-02
Machine: Linux (16 cores)
Tool: wrk 4.2.0, 4 threads, 50 connections, 10s per test

Servers:
  raw V8 concurrent:   1 V8 thread, serial JS + concurrent I/O, ESM modules
  raw V8 conc-pool:    16 V8 threads, each with concurrent I/O, ESM modules
  Node.js:             v22.22.2, http module, single thread

Changes since 2026-04-01:
  - ESM module system (replaced script mode)
  - URL/URLSearchParams polyfill (ada-url native)
  - #[zeroship_op] proc macro (zero overhead, generates identical code)
  - Per-app env vars (HashMap instead of process env)
  - Fix: copy module namespace exports to plain object (avoids exotic object overhead)

  vs old baseline (2026-04-01)
==================================================

Scenario                    Old(concurrent)  New(concurrent)  Delta
1. ping/pong                    132,552         148,338       +12%

Root cause of setTimeout regression: heavier EventLoopState struct (added
env_vars, url polyfill globals) increases per-tick overhead in the timer
drain path. Sync RPC and Promise paths recovered and exceeded baseline
after fixing module namespace → plain object copy.
