### [R9-T9] No test asserts `clock_resync` rejects bodies above the 4 KiB extractor cap or surfaces the A4 envelope on that 413 (MINOR, test-coverage-r9)
- **Files**: `crates/sandbox-agent/src/main.rs:148` (`small_limit = 4 * 1024`) + `crates/sandbox-agent/src/main.rs:197-199` (route doesn't override → inherits `small_limit`); `crates/sandbox-agent/src/handlers.rs:736-883` (handler reads `body: Bytes` and parses JSON unconditionally).
