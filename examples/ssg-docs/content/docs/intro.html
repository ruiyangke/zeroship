Getting started

The simplest deploy possible: worker: null. The whole app is HTML + maybe CSS + maybe images, served at content-addressed paths the gateway resolves through the manifest's assets[] map.

What gets emitted

{
  "worker": null,
  "rules": [
    { "match": { "kind": "prefix", "path": "/_assets/" }, ... },
    { "match": { "kind": "exact",  "path": "/" },           "action": { "kind": "static", "try": ["/index.html"] } },
    { "match": { "kind": "exact",  "path": "/about" },      "action": { "kind": "static", "try": ["/about.html"] } },
    { "match": { "kind": "exact",  "path": "/docs/intro" }, "action": { "kind": "static", "try": ["/docs/intro.html"] } },
    { "match": { "kind": "any" },                           "action": { "kind": "static", "try": ["$path", "/index.html"] } }
  ]
}

Why this matters

Static-only deploys cost the platform almost nothing to host (just blob storage + CDN egress). The gateway's per-request work is one in-memory cache lookup followed by sendfile-style streaming out of the blob store. No V8 cold start, no module loading, no isolate enter/exit.
