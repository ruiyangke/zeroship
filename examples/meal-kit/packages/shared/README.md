# Gather shared library

Common components, styling, localization and domain contracts for the apps in
[the meal-kit example](../../README.md). This is an example-local workspace
package. Database handlers and request credentials belong to the app servers.

The shadcn components use Base UI and remain editable here. App-specific
compositions stay with their app. Lingui extracts the shared library and both
apps into the catalogs in this directory.
