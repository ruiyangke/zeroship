# Your zeroship app

This is a starter project. Talk to the agent in the editor to start
building — it'll edit these files and run commands here.

## Layout

- `src/App.tsx` — main React component
- `src/main.tsx` — entry point
- `index.html` — HTML shell (Tailwind via CDN)
- `vite.config.ts` — Vite config (host 0.0.0.0, port 5173)

## Running locally

```bash
npm install
npm run dev
```

## Publishing

Click "Publish" in the editor — the agent runs `npm run build` and
the resulting bundle is deployed to the platform at
`https://{your-app-slug}.zeroship.ai`.
