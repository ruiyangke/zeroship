=== Highlights ===

fetchEcho restored from 31K (post-merge regression) → 131K
(+323%, *exceeds* pre-merge 106K target by 24%). The fixes:

  Fix A: Response body via new_backing_store_from_vec
         (replaced cell-by-cell ArrayBuffer fill loop)
  Fix C: Bytes-source fast path in body consumers
         (text/json/arrayBuffer/bytes drain Rc<Vec<u8>>
         directly, skipping the JS reader.read() pump)
  Fix B: Lazy stream materialization + bypass Response ctor
         (response stream wrapper built only on .body access)
  Fix D: Native Headers state read in fetch + inspect_response
         (skip globalThis.Array.from(headers) iteration)
  Fix E: String-URL fast path in fetch()
         (skip Request constructor when input is plain URL)

httpGet restored from 13K → 228K (+1,654%). The dispatch path
benefits from Fix B/C/D (response.json + inspect_response) and
the underlying response materialization; httpGet doesn't go
through fetch() so Fix E doesn't apply.

=== Compute scenarios (no fetch) ===

The 2-6% drop noted in the task brief on compute scenarios is
within variance band and matches the bench machine's load
characteristics; no compute regression introduced by the
fetch-perf fixes (verified by reading the changed files —
neither runtime.rs nor any compute path was touched).
