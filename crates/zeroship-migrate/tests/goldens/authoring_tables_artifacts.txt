# PROVENANCE, because a golden's worth is entirely its provenance.
#
# This file was CAPTURED from the OLD path - `render_artifacts` driven by the
# authoring-table walker - before the consumer was switched, and then 81 lines
# were REMOVED and 72 ADDED by hand. Every one of those 153 lines belongs to one of
# eight carrier streams, and every one is a place where the deleted walker described a
# database the server does not have:
#
#   carrier:pk_replace_single           the key stayed on the replaced column
#   carrier:pk_replace_composite        the table-level clause never appeared
#   carrier:pk_drop                     `primaryKey: null` never appeared
#   carrier:pk_add                      `primaryKey: null` survived an installed key
#   carrier:pk_replace_drops_identity   `.autoIncrement()` outlived the dropped identity
#   carrier:pk_replace_then_renamed     both of the above, composed with a rename
#   carrier:pk_replace_then_drop        two alterPrimaryKey ops composed
#   carrier:attached_partition_dropped  a dropped partition stayed a table
#
# SIX of the eight are adjudicated directly by a live PostgreSQL in
# tests/env_db_ts_matches_the_server_pg.rs, which applies the migration for real, reads
# the answer out of pg_catalog, and asserts the artifact declares it. The two
# `_then_` streams are compositions of ops each of which IS adjudicated there.
#
# NOTHING ELSE MOVED, and that is the load-bearing half. All 27 recorded op fixtures
# are byte-identical across the move. Every `sha|runtime.json` line was unchanged -
# `schema.runtime.json` is rendered from the `FieldDef` map and the runtime-metadata
# projection, neither of which CONSUMER 2 touches. No `constraint`, `index`,
# `partition_by`, `schema` or `options` line moved on any stream.
#
# SIX `sha|runtime.json` LINES MOVED LATER, under step 4 consumer 3, which replaced the
# walker that produced the `FieldDef` map. They are
# `carrier:attached_partition_dropped` and `carrier:unique_constraint_lifecycle`, on
# three dialects each - the two carriers here that cross a divergence that move fixed (a
# dropped partition left in the map, and a dropped UNIQUE outliving its constraint). The
# control worked: zero `sha|env.db.ts` lines and zero per-field lines moved, so consumer 3
# stayed inside the artifact it owns. `tests/goldens/field_defs_artifacts.txt` records the
# same two hashes, reduced by different code from the same `render_artifacts` call.
#
# The net line count fell by 9 = 3 dialects x 3 lines, which is the `p1` table
# leaving `carrier:attached_partition_dropped` - the one table this move removes from
# an artifact.
#
# There is deliberately NO re-bless environment variable, matching
# tests/op_fixture_goldens.rs. Sorted for a readable diff; the test compares sets and
# lengths, not order.
#
# SECOND EDIT: three `fluent_scalars|*|sha|runtime.json` lines only. The wire `FieldDef`
# gained `precision`/`scale` so a `t.numeric(p, s)` column stops being spelled as a bare
# `number` - the collision that made a SQLite rebuild re-declare it REAL and copy its

# artifact does not carry the field defs, so only the `runtime.json` hash moves; ZERO
# `sha|env.db.ts` lines and ZERO per-column lines moved, which is the same containment
# control the first edit used.
#
# THIRD EDIT: the postgres-only `dialectal_ops` fixture now refuses SQLite and MySQL
# artifact generation. An absent exact target leg no longer silently discards the
# wrapper and emits artifacts for the prefix before it. Each old per-artifact group is
# replaced by one explicit refusal line; the PostgreSQL outcome is byte-identical.
#
# FOURTH EDIT, AND IT REVERSES THE THIRD. An `Op::Dialectal` whose `legs` map has no
# key for the render target now CONTRIBUTES NOTHING instead of refusing; only
# `Expr::Dialectal` still refuses, and that asymmetry is deliberate (an absent
# EXPRESSION leg leaves no value to write in a statement that runs anyway, an absent OP
# leg just means this backend has no work here). So the two refusal lines the third
# edit installed are gone and the fourteen lines each replaces them are back.
