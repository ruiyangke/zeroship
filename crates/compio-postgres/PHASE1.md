## Beyond-verbatim adaptations

- **Removed every `#[cfg(feature = "runtime")]` guard.** In tokio-postgres this feature toggled the tokio-based convenience layer; in our crate, we always want the connect path enabled.
- **`tokio::io::{AsyncRead, AsyncWrite}` → `compio::io::{AsyncRead, AsyncWrite}`** in every ported file that used it (config.rs, cancel_token.rs).
- **Tightened `ToStatementType::into_statement` from `pub` to `pub(crate)`** to satisfy private-interfaces lint — the method accepts `InnerClient`, which is a crate-private type.
- **`NoTls`/`NoTlsStream` in the `tls` stub** are functional (the real Phase 2 implementation uses the same shape). `NoTlsStream` is uninhabited (`enum NoTlsStream {}`), and its `AsyncRead`/`AsyncWrite` impls are trivially satisfied via `match *self {}`.
- **Note on `TlsStream` vs `AsyncRead + AsyncWrite` bounds:** tokio-postgres defines a separate `TlsStream` trait (with `channel_binding()`). Our Phase 1 stub uses `AsyncRead + AsyncWrite + Unpin` directly for simplicity. Phase 2 will introduce the real `TlsStream` trait with `channel_binding()`.
- **Preserved copyright headers** on every ported file (tokio-postgres is MIT/Apache-2.0, copyright Steven Fackler, 2016+).

## Ready for Phase 2 to fill in

Phase 2's scope (per the plan):
1. **`codec.rs`** — replace the stub `FrontendMessage` enum with the full variant set; port the framing logic. Integrate our existing `BufStream` (with the 64MB length cap) from `crates/pg/src/stream.rs`.
2. **`socket.rs`** — real `Socket` wrapper over `compio::net::{TcpStream, UnixStream}`. Delete the placeholder `AsyncRead`/`AsyncWrite` impls from the Phase 1 stub in `lib.rs` and move them to `socket.rs`.
3. **`maybe_tls_stream.rs`** — `MaybeTlsStream<S, T>` enum.
4. **`tls.rs`** — replace the `lib.rs` stub module with a real file. Introduce the `TlsStream` trait, `ChannelBinding`. Keep `NoTls` shape from Phase 1 stub.
5. **`connect_tls.rs`** — TLS upgrade state machine.
6. **`connect_socket.rs`** — TCP/UDS dial + our socket2 keepalive.

Once Phase 2 is in, delete the matching stub modules from `lib.rs`.
